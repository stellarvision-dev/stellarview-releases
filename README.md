# 별뷰

**위성영상과 일반 사진을 한 프로그램으로 보고, 옆에 있는 Claude 에게 말로 분석·라벨링을 시키는 뷰어.**

## 이런 일에 쓴다

- 위성영상(GeoTIFF·NITF·TIL·JP2 등)을 열어 밴드 조합·밝기를 바꿔 가며 본다.
- 일반 사진(JPG·PNG 등)을 폴더째 넘겨 가며 본다.
- 「이 영상에서 건물을 찾아 사각형으로 표시해 줘」처럼 말로 라벨링을 시킨다.

## 특징

| | |
|---|---|
| **위성영상 그대로** | GDAL 을 품고 있어 따로 깔 것이 없다. 좌표계·메타데이터를 읽는다. |
| **큰 영상도 빠르게** | 피라미드 타일로 필요한 부분만 그린다. |
| **AI 터미널** | 영상 옆에 Claude 가 떠 있다. 보고 있는 화면·선택 영역을 그대로 넘긴다. |
| **스스로 새 버전** | 새 버전이 나오면 앱 머리줄에 설치 단추가 뜬다. |
| **앱 안에서 의견 보내기** | 피드백 단추로 버그·제안을 바로 보낸다. 계정이 없어도 된다. |

## 받기

[**최신 버전 받기**](https://github.com/stellarvision-dev/stellarview-releases/releases/latest)

> **1.0.0 을 쓰고 있다면** 앱 안의 자동 업데이트로는 1.0.1 을 받을 수 없다. 위 링크에서 설치 파일을 받아 한 번 직접 설치한다. 설정과 라벨은 그대로 남고, 그다음 버전부터는 다시 자동으로 업데이트된다.

- `stellarview_<버전>_x64-setup.exe` — 보통 설치 파일.
- `stellarview_<버전>_x64-offline-setup.exe` — 인터넷이 없는 PC 용(WebView2 설치본 포함).

- Windows 10·11 (64비트)
- AI 기능을 쓰려면 [Claude Code](https://claude.com/claude-code) 가 깔려 있고 로그인돼 있어야 한다. 보기만 할 때는 없어도 된다.
- 관리자 권한 없이 사용자 폴더에 깔린다.
- 아직 코드 서명이 없어 「Windows의 PC 보호」 창이 뜰 수 있다. 「추가 정보 → 실행」을 누른다.
- 문제가 생기면 `%LOCALAPPDATA%\ai.stellarvision.stellarview\logs` 의 로그를 피드백에 붙여 보낸다.

AI 기능을 쓰면 보고 있는 영상 일부와 메타데이터가 Claude(Anthropic)로 보내진다. 밖으로 보내면 안 되는 자료는 AI 기능 없이 본다.
이 저장소에는 설치 파일과 설명서만 있다. 소스는 공개하지 않는다.
