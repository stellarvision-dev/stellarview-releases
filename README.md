# 별뷰

**위성영상과 일반 사진을 한 프로그램에서 표시하고, 옆 창의 Claude에게 대화로 분석과 라벨링을 요청하는 뷰어.**

## 주요 용도

- 위성영상(GeoTIFF·NITF·TIL·JP2 등)을 열어 밴드 조합과 밝기를 조절하며 확인한다.
- 일반 사진(JPG·PNG 등)을 폴더 단위로 넘겨 가며 확인한다.
- 「이 영상에서 건물을 찾아 사각형으로 표시해 주세요」처럼 대화로 라벨링을 요청한다.

## 특징

| | |
|---|---|
| **위성영상 직접 표시** | GDAL이 포함되어 있어 별도로 설치할 프로그램이 없다. 좌표계와 메타데이터를 읽는다. |
| **대용량 영상 고속 표시** | 피라미드 타일로 필요한 부분만 표시한다. |
| **AI 터미널** | 영상 옆에서 Claude를 실행한다. 현재 화면과 선택 영역을 Claude에게 전달한다. |
| **자동 업데이트** | 새 버전이 출시되면 앱 상단에 설치 단추가 표시된다. |
| **앱 내 피드백** | 피드백 단추로 버그·제안을 바로 전송한다. 계정이 없어도 된다. |

## 다운로드

[**최신 버전 받기**](https://github.com/stellarvision-dev/stellarview-releases/releases/latest)

> **1.0.0을 사용 중이라면** 앱 내 자동 업데이트로는 새 버전을 받을 수 없다. 위 링크에서 설치 파일을 내려받아 한 번 직접 설치한다. 설정과 라벨은 그대로 유지되고, 이후 버전부터는 다시 자동으로 업데이트된다.

- `stellarview_<버전>_x64-setup.exe` — 일반 설치 파일.
- `stellarview_<버전>_x64-offline-setup.exe` — 인터넷이 연결되지 않은 PC용(WebView2 설치본 포함).

- Windows 10·11 (64비트)
- AI 기능을 사용하려면 [Claude Code](https://claude.com/claude-code) 또는 Claude 데스크톱이 설치되어 있어야 하며, 로그인이 필요하다. 영상 보기 기능만 사용할 때는 필요하지 않다.
- 관리자 권한 없이 사용자 폴더에 설치된다.
- 아직 코드 서명이 없어 「Windows의 PC 보호」 창이 표시될 수 있다. 「추가 정보 → 실행」을 누른다.
- 문제가 발생하면 `%LOCALAPPDATA%\ai.stellarvision.stellarview\logs`의 로그를 피드백에 첨부하여 전송한다.

AI 기능을 사용하면 현재 표시 중인 영상의 일부와 메타데이터가 Claude(Anthropic)로 전송된다. 외부 전송이 금지된 자료는 AI 기능 없이 확인한다.

이 저장소에는 설치 파일과 설명서만 있다. 소스는 공개하지 않는다.
